# Garantia de Qualidade e Revisão de Código — Módulo de Inscrições

Este repositório reúne a solução do exercício prático sobre **Fundamentos de Teste de Software**, focado na inspeção estática de rotinas em Python, localização de defeitos e categorização de cenários de teste.

---

## 📌 Contexto do Projeto
O propósito do trabalho foi desempenhar o papel de Analista de QA no módulo de cadastros do sistema de eventos da **TechSolutions**, assegurando a conformidade com as especificações de negócio e apontando inconsistências na lógica antes que o código entrasse em produção.

---

## 🛠️ Ações Realizadas
* **Avaliação de Requisitos e Regras do Sistema:** Checagem dos critérios de faixa etária mínima, controle do saldo de vagas e concessão de descontos via cupom.
* **Simulação Lógica (Identificação de Falhas):** Rastreamento do código Python para localizar erros nas funções de precificação e no fluxo de conclusão do cadastro.
* **Categorização de Testes:** Divisão clara entre testes **Funcionais** e **Não Funcionais** (abrangendo desempenho, carga e segurança), além da identificação dos **Níveis de Teste** aplicados (foco em Teste Unitário).
